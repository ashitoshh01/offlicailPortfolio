# Ashitosh Lavhate — Personal Portfolio

Computer Science Undergraduate — Applied AI, Backend Systems & Automation based in Pune, India.

Built with Next.js, [shadcn/ui](https://ui.shadcn.com/), TailwindCSS, and [Magic UI](https://magicui.design/).

## Features

- **Personal Profile & Hero:** Highlights applied AI, scalable backend architectures, and production products.
- **Categorized Skills:** Cleanly organized technical stack (Languages, Frontend, Backend, AI/ML, Databases & Infrastructure, Tools & Platforms).
- **Interactive Work Experience:** Timeline of leadership (CTO at E-Vakili, Google Student Ambassador (Ping), internships).
- **Featured Projects:** Showcasing DoOrDue, DES Unified Platform, FlowLens CLI, and AI Visual Inspection SaaS.
- **Achievements & Hackathons:** Documenting national hackathon rankings and competitions.
- **Integrated Blog:** Dynamic MDX-powered technical blog.
- **Responsive & Animated:** Fluid layout with smooth micro-interactions, dark/light theme switching, and dock navigation.

## Getting Started Locally

1. Clone repository:
   ```bash
   git clone https://github.com/ashitoshh01/portfolio
   ```
2. Install dependencies:
   ```bash
   npm install # or pnpm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
